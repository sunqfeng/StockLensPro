# 模拟执行修复与 RPS 前向对照 v1

建立日期：2026-10-24，北京时间。当前账户、历史成交与日结不重置、不重算；参数和跨策略买入排序不变。本轮唯一改变原账户交易判断的规则是涨跌幅限价修复。ATR、冷却期、连续分值排名、大盘过滤和组合仓位改造尚未启用。

## 执行规则修复

`stocklens/paper_trading.py` 的 `limit_locked` 按报价对应交易日期计算限价：

- 主板 ST：2026-07-06 前5%，当日起10%。
- 创业板自2020-08-24起、科创板为20%；北交所为30%；这些板块规则优先于名称中的ST。
- 限价按价格最小变动单位0.01元、ROUND_HALF_UP计算；无日期、非法价格及非有限数失败关闭。
- 新信号任务的 `paper_runs.code_version` 附带 `cn-limits-20260706-v1` 与执行文件哈希，历史任务记录不回写。该版本仍是报价判断，不是盘口成交撮合器；新股/重新上市等特殊无涨跌幅限制情形还需要更完整的历史证券状态数据。

规则来源：[深交所2026交易规则](https://docs.static.szse.cn/www/lawrules/rule/allrules/bussiness/W020260424690713155663.pdf)、[上交所2026交易规则与生效日期](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)。

## 与现有影子框架的边界

原 `sequoia_mysql_strategy/shadow_controls.py` 观察的是常规推荐登记与收盘日收益，不是模拟交易全部候选的14:45报价，成本和实验问题也不同。新观察器沿用其原子首次写入模式，放在看板项目内独立运行，避免将两个口径混用。它只读业务数据库，只写自己的研究JSON，不调用交易执行、推荐登记或技术评分任务。

## 冻结的实验合同

- 观察对象：当天成功的模拟信号任务中所有RPS候选，包括未成交的候选；原始评分、理由、数据库顺序、状态、配置版本和原始报价保留。
- 固定入场观测时间：每个交易日14:45，报价时间须在14:44—14:50，采集在14:50前结束。采集有数分钟时间差，不声称所有证券同一瞬间成交；它与账户约14:36的实际成交独立。
- 共同可用股票池：有至少22条近期日线，前20日波动率可计算，前一完成日成交额至少1亿元、HIGH质量、复权标记一致；排除ST、无有效实时价/量和涨跌停锁定报价。全部被排除成员及理由也保留。
- 匹配：板块×前一日成交额三分位×前20日波动率三分位。没有匹配市值、行业、beta等全部风格因素，差值不能直接称为alpha。
- 预先固定种子：17、43、97；必须一起报告，不按表现挑选。随机排序基于版本、日期、种子和代码的SHA256，与输入顺序及进程无关。
- 各候选均等名义预算10万元，100股整手；费用、税费和滑点在入场时从账户配置冻结，不再读取后来参数。

| 研究组 | 用途 |
|---|---|
| `rps_all` | 共同可用股票池内的RPS候选全集，诊断信号本身 |
| `universe_matched_seed17/43/97` | 每个匹配层按RPS候选人数随机抽取的全股票池对照，允许与RPS重叠并记录重叠数 |
| `legacy_top3` | 同一研究可用池内，按原分数及信号记录顺序取前三；不等于带现金/持仓约束的账户实际买入 |
| `rps_random3_seed17/43/97` | 同一RPS池中随机三只，诊断原排序有没有增益 |
| `rps_live_proximity` | 额外实验臂：按实时价重新检查≥历史120日高点90%；原始候选不因失败而删除，实际买入规则也不受它改变 |

RPS原始连续值和120日高点从已登记理由提取并保存；无法解析时留空，不伪造连续评分。候选评分缺失时，候选全集仍保留，但前三排名明确不可用，不将缺失分数填为0。

## 收益与覆盖率

按市场交易日历计算入场后1/5/10/20日收盘，不用股票“下一条有行情的日期”冒充目标日。真实入场是实际不复权价，因此整段复权行情、复权混用、缺少参考价或前收盘价链断裂均标记不可评估。

每笔按成交价加减单边滑点、双边佣金与卖出税费计算，金额逐项取分，成交价保留4位小数。保存 `net_return_pct`（实际投入成本为分母）和 `budget_return_pct`（10万元预算为分母，含闲置现金）。这是固定持有信号诊断，不模拟账户的止盈、止损与资金占用竞争。

缺日、停牌、目标日跌停不能卖出、低质量或复权异常均保留原因，收益留空，不补0。完整组均值 `mean_net_return_pct` 只有覆盖率100%才给出；`observed_mean_net_return_pct` 是仅可评估样本的均值，必须同时看覆盖率，可能有缺失选择偏差。

对照差值分别为RPS全集减匹配随机池、原前三减候选随机三只。另保存沪深300、上证及创业板指的入场时点价格与目标日收盘的价格指数收益；指数不扣复制费用、不含现金股息，与股票扣费结果的差值不能直接解释为alpha。

每日收盘第一次快照及成熟收益文件不覆盖。观察器停机丢失某个市场日时，相关收益会明确缺资料，当前版本不使用后来修订日线悄悄补全首次证据。跨日期重复持股及重叠20日收益存在相关性，报告不自动生成独立交易假设下的显著性或年化收益。

## 文件与定时任务

服务器根目录：`/srv/python/StockLensPro`。输出根目录：`outputs/paper_signal_research/paper-rps-controls-v1/`。

- `cohorts/YYYY-MM-DD.json.gz`：真实14:45前向入场与组员。
- `previews/YYYY-MM-DD.json.gz`：历史收盘预演，使用当前元数据，不能计入前向成绩。
- `market_closes/YYYY-MM-DD.json.gz`：首次收盘观测及指数收盘。
- `outcomes/入场日/01d.json`、`05d.json`、`10d.json`、`20d.json`：到期结果与覆盖率。
- `checks/YYYY-MM-DD.json`：当天首次结算检查记录；重跑不会改写旧检查。
- `task_logs/paper_research.log`：任务事件和失败类型，不输出配置对象或连接串。

新任务使用独立的 `/tmp/stocklens_paper_research.lock`，不占原交易锁。采集14:45、结算16:05；外部超时限制5分钟。当前端页面尚不展示研究结果，先积累可核查的冻结证据。

```sh
python scripts/run_paper_research.py capture
python scripts/run_paper_research.py settle
python scripts/run_paper_research.py preview --date 2026-10-23
python -m unittest discover -s tests -q
```

`capture` 和 `settle` 只接受当前真实交易时段；CLI只有 `preview` 允许指定历史日期。预演和生产采集路径分开。Gzip用于降低长期采集的磁盘占用。

## 验证与判定

执行修复有先失败后通过的回归测试。分组、原子冻结、随机匹配、价格口径、费用计算、市场日期及不可成交情况均有单元测试。

历史预演仅用于接线和覆盖检查，不能视为前向盈利证据。按预先固定的1/5/10/20日及所有种子查看扣费期望、对照差值、覆盖率和尾部损失。正式采纳或淘汰方案需要多个市场阶段、冻结样本外验证，并处理日期聚类、重叠持有期及多重比较。
